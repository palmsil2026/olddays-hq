# ชุดทดสอบ (รันก่อน push ทุกครั้งที่แตะ gas/Code.gs หรือ index.html)

```bash
node tests/member.test.js
```

- ใช้ Node ล้วน ไม่ต้องติดตั้งอะไร — จำลองชีตในหน่วยความจำ ไม่แตะ Google Sheets จริง
- `node tests/cache.test.js` — ยืนยันว่าการจำข้อมูลใน 1 คำขอไม่ทำให้อ่านค่าเก่าหลังเขียน
- `node tests/perf.bench.js` — นับจำนวนครั้งที่คุยกับ Google Sheets ต่อ action (ตัวแปรหลักของความหน่วง)
- member.test ครอบ: ระบบสมาชิก (สมัคร/สะสม/แลก/หมดอายุ/ต่ออายุ/ยกเลิกรายการ/สิทธิ์/นำเข้า LMWN), สต๊อกเทียน,
  ตัวอ่านอีเมลปิดรอบ POS (ส่วนลด + โปรสมาชิก + หมวดสินค้า จากอีเมลจริง 23/9), การ์ดกลุ่มไม่มีตัวเงิน
